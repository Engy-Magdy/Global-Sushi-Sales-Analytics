## 🌟 About The Project
Welcome to the data kitchen! This project dives deep into a multi-regional dataset for a global sushi restaurant chain, processing and analyzing sales across four major international markets:
* 🇺🇸 **United States**
* 🇬🇧 **United Kingdom**
* 🇨🇦 **Canada**
* 🇩🇪 **Germany**

---

## 🚀 Key Features & Architecture

| Component | Description | Status |
| :--- | :--- | :---: |
| 🔄 **Master Dataset Aggregation** | Unifying multi-country sales records, dates, and purchase methods into a robust master DataFrame. | ✅ Completed |
| 🔪 **Country-Specific Partitioning** | Slicing and filtering data dynamically to create dedicated DataFrames for each target region. | ✅ Completed |
| 📈 **Statistical Insights** | Computing core metrics per country, including **Total Sales**, **Mean (Average)**, and **Median** values to handle outliers. | ✅ Completed |

---

## 🛠️ Tech Stack & Tools
* **Language:** Python 🐍
* **Core Library:** Pandas (for advanced data manipulation, filtering, and aggregation) 🐼
* **Environment:** Visual Studio Code & Git 💻
